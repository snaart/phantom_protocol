ACTION REQUIRED: No signing key Secret is configured.
The Deployment will fail to start until a Secret is available.

Create the Secret manually:

  kubectl create secret generic {{ include "phantom-core.fullname" . }}-signing-key \
    -n {{ .Release.Namespace }} \
    --from-file=hybrid_signing_key=/path/to/hybrid_signing_key.bin

Or re-install with:

  helm upgrade {{ .Release.Name }} ./docs/operations/helm/phantom-core \
    --set signingKey.existingSecret=<your-secret-name>
